# مُنظّم يومي – أبو إلياس

تطبيق Flutter عربي تأسيسي لتنظيم الروتين اليومي، حفظ حالة إنجاز المهام، ضبط تنبيهات محلية، وحساب تذكير المغرب حسب موقع الجهاز.

## البناء محلياً
```bash
flutter create --platforms=android --project-name abu_elias_routine .
flutter pub get
flutter build apk --release
```

ملف إعداد Codemagic موجود في جذر المشروع باسم `codemagic.yaml`.

> هذه نسخة تأسيسية غير مختبرة على جهاز فعلي بعد. يلزم اختبار صلاحيات الإشعارات والموقع وتوافق مواعيد التنبيه قبل الاعتماد عليها.
